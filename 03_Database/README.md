
# SIGR Database

Base de datos PostgreSQL para el Sistema Integral de Gestión de Restaurante.

## Archivos

- init.sql -> crea la estructura de tablas.
- seed.sql -> inserta datos iniciales.
- backup.backup -> archivo de respaldo de referencia.

## Configuración

Tecnología:
- PostgreSQL

## Ejecución

1. Crear la base de datos:

```sql
CREATE DATABASE sigr;
```

2. Ejecutar:

- init.sql
- seed.sql
